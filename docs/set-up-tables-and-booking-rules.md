Open **Settings** on the Reservations page.

## Booking rules

Opening hours come from your Company Location settings. Bookings can start from opening time up to closing time.

- **Bookings** narrows the window, for example last bookings at 21:00. Leave it empty to take bookings from opening to closing.
- **Break** is optional. Set it between lunch and dinner and nothing can start in it.
- **Minimum notice (hours)** and **How far ahead (days)** control how soon and how far in advance customers can book.
- **Times on the minute marks** sets how often a start time is offered.
- **Dining time (minutes)** is how long a table is held for each booking.
- **Turnaround (minutes)** is held after each booking to reset the table.

Customers never see the dining time or the turnaround. Press **Save settings**.

## Tables

Under **Tables**, press **Add** and enter each table's **Name** and number of **Seats**.
